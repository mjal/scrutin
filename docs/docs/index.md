# Accueil

Scrutin est un logiciel libre de vote par internet [secret](/secret) et [vérifiable](/verifiabilite) utilisant [Belenios](https://www.belenios.org), un protocole de vote développé par le CNRS et l'INRIA, via [Sirona](/sirona).

Le code source est ouvert et disponible [ici](https://github.com/mjal/scrutin).

Scrutin est développé en Rescript (une variante d'OCaml qui compile en Javascript) et en React Native, permettant de compiler pour iOS, Android et le web. (Les versions mobiles seront bientôt accessibles.). L'accent est mis sur l'interface et l'expérience utilisateur.

Une petite extension de protocole de Belenios est en développement. [(plus d'infos)](/extension)
